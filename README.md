# UI-UX-Design-of-SKILLSWAP

## Project Overview
SkillSwap is a skill-sharing platform designed to help people connect, exchange knowledge, and learn from one another.

## Key Features
- User onboarding and profile creation
- Add skills to teach and skills to learn
- Discover users based on shared interests
- Send and manage learning requests
- One-to-one chat and connection management
- Track completed learning sessions

## Design Process
- User-centered design
- User flows and information architecture
- Wireframing and prototyping
- UI design and usability considerations
